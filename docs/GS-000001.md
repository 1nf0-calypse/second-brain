# Getting Started — Second Brain MCP

## Was ist Second Brain MCP?

Second Brain MCP verbindet einen bestehenden Obsidian-Vault lokal mit Claude Desktop und
hält einen lokalen Index aktuell. Deine Originalnotizen werden beim Setup und Indexieren
nicht migriert oder verändert.

## Bevor du anfängst

Du brauchst Windows, Obsidian 1.8.0 oder neuer, Node.js 24 LTS, Claude Desktop und das
Second-Brain-MCP-Plugin-Paket.

## Erste Schritte

1. Kopiere `manifest.json`, `main.js` und `styles.css` nach
   `<Vault>\.obsidian\plugins\second-brain-mcp\`.
2. Starte Obsidian neu und aktiviere **Second Brain MCP** unter **Community plugins**.
3. Öffne **Second Brain MCP: Open setup** über die Befehlspalette.
4. Gib den vollständigen Vault-Pfad ein und wähle **Test local service**.
5. Kopiere die Konfiguration, füge sie in Claude Desktop unter
   **Settings → Developer → Edit Config** in das vorhandene `mcpServers`-Objekt ein und
   starte Claude Desktop neu.
6. Wähle in Obsidian **Update local index**.

## Die wichtigsten Funktionen

- **Claude Desktop verbinden** — nutzt eine lokale MCP-Verbindung ohne zusätzlichen
  KI-Anbieter-Schlüssel. Details:
  [DOC-000001](DOC-000001-claude-desktop-setup.md).
- **Lokalen Index pflegen** — verarbeitet nur Änderungen und kann sicher neu aufgebaut
  werden. Details: [DOC-000002](DOC-000002-local-index.md).

## Wenn etwas nicht funktioniert

- Lade das Plugin nach jedem Paket-Update durch Deaktivieren/Aktivieren oder einen
  Obsidian-Neustart neu.
- Prüfe, ob der Vault-Pfad einen lesbaren `.obsidian`-Ordner enthält.
- Prüfe, ob `node --version` mindestens Version 24 meldet.
- Prüfe die Claude-Konfiguration auf gültiges JSON und starte Claude Desktop neu.
- Nutze die Fehlerbehebung in den beiden Feature-Guides; ein fehlgeschlagener Setup- oder
  Indexlauf verändert keine Originalnotiz.

## Nächste Schritte

Verbinde zuerst Claude Desktop und erstelle danach den lokalen Index. Suche, Graph,
kontrollierte Schreiboperationen sowie ChatGPT und Mistral folgen in späteren Sprints.
